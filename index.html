Ekstensi diperlukan untuk pengecekan otomatis

Gunakan Google Chrome atau Microsoft Edge, unduh paket ekstensi, lalu pasang folder hasil ekstraknya.

Unduh Ekstensi

Panduan Memasang Ekstensi

Penting: ekstrak file ZIP terlebih dahulu. Saat memilih ekstensi di Chrome/Edge, pilih folder extension, bukan file manifest.json, background.js, atau content.js di dalamnya.
  1. Klik Unduh Ekstensi, lalu ekstrak file extension.zip ke sebuah folder.
  2. Klik Buka Halaman Ekstensi. Jika browser tidak membukanya otomatis, alamat sudah disalin—tempelkan ke address bar lalu tekan Enter.
  3. Aktifkan Developer mode / Mode developer.
  4. Klik Load unpacked / Muat yang belum dipaketkan.
  5. Pilih folder extension hasil ekstrak. Pada jendela pemilih folder, file di dalam folder memang tidak terlihat; cukup klik Select Folder.
  6. Buka Details ekstensi dan aktifkan Allow access to file URLs / Izinkan akses ke URL file.
  7. Muat ulang aplikasi. Status akan berubah menjadi Ekstensi terpasang.

Tentang Aplikasi

Versi 6.0

Aplikasi Daftar Nominatif Pencairan membantu menyiapkan rekap dan eviden layanan pertanahan dari data Excel.

Pengolahan dataMembaca Excel pendapatan harian, mengelompokkan layanan ke MAK dan sublayanan, serta menampilkan status berkas.
Periode dan monitoringMemfilter data per bulan, merangkum tahun berjalan, dan memantau backlog tahun sebelumnya.
Eviden pencairanMenyusun daftar nominatif, ringkasan volume, dan file Excel siap diunduh.
Pemecahan BidangKhusus sublayanan Pemecahan Bidang, aplikasi dapat memperoleh jumlah bidang melalui ekstensi setelah pengguna login ke ATR/BPN.
